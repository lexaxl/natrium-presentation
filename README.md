# Натриум — презентация лендинга

Краткая презентация проекта для заказчика: задача, кликабельный прототип, заложенная функциональность, архитектура, ограничения и план.

Открыть: https://lexaxl.github.io/natrium-presentation/

- `index.html`, `assets/` — сама презентация.
- `prototype/` — собранная копия сайта на заглушках. Счётчик Метрики из копии вырезан, индексация закрыта.
- `mockups/` — макеты первого экрана и состояний формы, по которым собирался сайт.

Обновить прототип после новой сборки сайта:

```bash
cd ../onepagesite && npm run build
cd ../natrium-presentation && node tools/sync-prototype.mjs ../onepagesite/dist
```

Исходный код сайта и материалы планирования живут в отдельном закрытом репозитории.
